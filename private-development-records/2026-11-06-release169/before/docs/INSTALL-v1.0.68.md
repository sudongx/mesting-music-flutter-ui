# 安装与配置 Mesting Music 1.0.68

正式 release APK：`release/Mesting-Music-v1.0.68.apk`，版本 `1.0.68`、Android code `89`、包名 `com.mesting.music`，使用原证书。由用户自行保留数据覆盖安装；本轮未连接设备或执行安装，不能视为88→89升级验收。

1. 在 NAS 完成签名助手部署并确认服务就绪。仅 HTTP 进程存活不代表原生签名组件已就绪。
2. 在 Mesting 的汽水平台进入“设置 → 汽水签名服务”。填写实际 HTTP 或 HTTPS 地址及助手访问令牌。例如 `http://192.168.1.8:18899/` 或 `https://你的域名/qishui-signer/`；也可以粘贴完整 `/sign` 地址。
3. 点击“测试连接”。通过表示读取到匹配的设备上下文并得到应用签名，不表示已完成官方整曲播放。失败时核对令牌、路径、助手就绪状态或连接提示。
4. 点击“保存并使用”。只测试不会改变当前播放配置，保存后才使用自建助手；失败不自动回退公共服务。无需把私有令牌发到聊天或写进APK。
5. 手动播放一首本人账号有权限的汽水歌曲，核对时长、中段和尾段。点击胶囊进入“音乐”Tab，点击封面切换歌词并返回，检查底部Tab仍在。
6. 手动检查单曲插队保留待播、“播放全部”替换队列；随机入口仅随机选一首。

HTTP/HTTPS协议选择与服务是否可达是两件事：手机须能访问所填地址；外网访问、反向代理、证书与助手的实际部署由用户核对。本轮不操作NAS、FRP、防火墙、账号、奖励或后台。
