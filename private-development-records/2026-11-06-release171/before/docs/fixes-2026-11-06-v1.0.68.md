# Mesting Music 1.0.68 / code89

本版按用户确认增加自建汽水签名助手配置，支持 HTTP / HTTPS，并整合协作者的字体与直接播放改动。正式包仍为原包名 `com.mesting.music`、原证书、Beta 原生/UI flavor 的 **release** 构建。

## 签名助手

- 入口：设置 → 汽水签名服务。地址支持端口、反向代理前缀及末尾 `/sign`；访问令牌单独输入，使用既有加密 vault 的独立命名空间保存，完成持久读回后才发布新设置。
- 配置、存储、请求适配、连接测试及页面分别解耦。创建平台 API 不读取签名配置；需要签名或主动进入设置才读取。保存后撤销旧的在途请求，保留当前账号 jar；已派发写入继续遵守未知结果 journal，不自动重放。
- 自建助手必须从 `/config` 返回真实 PC `device_id/iid/fp/user_agent`。应用按返回的 LunaPC 版本构造相同上下文，移除旧 `cdid` 字段，并按精确 URL、正文和 UA 请求签名。匿名测试先读取配置，再请求一次签名，不向汽水派发业务请求。
- HTTP 仅在所选助手请求的局部 Dart Zone 开放，实际源码依据本机锁定 Flutter 的 `ui/hooks.dart`；助手禁用重定向。没有改全局 Android 网络策略，也不放宽官方 API 的 HTTPS 或证书验证。
- 访问令牌仅出现在助手 HTTP 外层 Authorization。Cookie、CSRF、账号 token 和扫码 nonce 不交给助手；只接收签名头，自建返回的 device_id 必须与所签请求一致。
- 自建服务失败不自动回退公共服务。分别提示 401/403、404、429、400/415/422、500、503和连接超时；不展示服务原始正文或凭据。

## 播放和导航

- 汽水胶囊选择原有“音乐”Tab，不推入独立 `/player`。
- 点击当前歌曲封面或歌词按钮，在同一 Tab 内切换歌词视图；按用户提供的汽水官版截图调整为顶部小封面/曲目信息/播放、大字号左对齐歌词、当前句高亮与上下渐隐。选句只预览，显式点击时间旁的播放入口才 seek 并播放；手动浏览暂停跟随，8秒无操作或点击“回到当前句”后恢复。变高长句按真实字体/缩放测量，保留底部Tab。返回封面、系统返回、分享、收藏和待播复用既有业务与唯一 audio handler，不增加虚假的点赞数或卡拉OK功能。
- 单曲点击只插队并保留手动待播；页面列表不再变成隐式替换队列。明确“播放全部”才提交整批快照。汽水“随机播放”改称“随机选一首”，保留待播，避免另一处隐式整批替换。
