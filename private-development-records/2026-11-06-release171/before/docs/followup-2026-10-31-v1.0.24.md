# 1.0.24 基线上的一起听、音源说明与登录插画更新

2026-10-31（Asia/Shanghai）。工作目录 `D:/AnLi`，基线为 beta / `b6bcd5425e0df3e03febdd460b56d0ed42004c52`。本轮用户明确确认实施；尚未指定下一版版本号，没有覆盖 1.0.24 或旧版的冻结 APK、源码 ZIP、标签或 Release。

## 已实施行为

- 网易云房间进行中，播放器右上角菜单优先提供“管理一起听 / 退出一起听”。房间面板的退出按钮移到成员区域，不必滚动到好友列表底部。两个入口使用同一确认流程，取消不请求接口；确认后调用现有官方结束接口。成功时停止本机的同步订阅和心跳、清理房间状态，保留当前歌曲、队列、进度和播放/暂停状态。失败或结果未知时保留房间、提示手动核对，不自动重放写操作。酷狗一起听未修改。
- 同步请求以代次判断是否仍有效；退出前发起的状态、队列及播放指令响应不能重新激活房间或重新控制播放。位置请求仍遵守主动授权和原有脱敏边界。
- 私信历史及会话摘要支持 `generalMsg`、`body`、`msgBody` 和 JSON 字符串嵌套消息卡片。标题、说明、平台明确以秒为单位的时长进入原生卡片与详情页；不从任意 roomId、模糊的 duration 数字或好友资料猜测记录。读取记录不创建房间、不加入邀请、不发送或补发私信。
- 卡片带有网易云网页链接时，可由用户点击查看原始详情。仅解析受限的 `orpheus://nm/redirect` / `webview` 包装及精确网易云 HTTPS 网页目标；不执行消息中的外层深链、脚本或 HTML，不向网页注入本机账号 Cookie。卡片未提供的统计数据不补造，未附网页时明确显示该状态。原生详情及网页详情均检查账号切换。
- “设置 → 网易云播放与同步”的音源面板展示独立保存的“酷狗概念版账号”和账号状态，不新增开关，不切换当前听歌平台，不在线探测会员权益。账号恢复中、存储读取失败、尚未登录和已保存登录分别显示。说明统一为“网易云官方 → 酷狗概念版账号 → 其他备用音源 → BugPk”，公开酷狗音源另标明为公开音源。
- 用户提供的透明 PNG 原字节保存为 `assets/branding/login/companions-bottom.png`，仅纳入 Beta 资源。8 种具体登录方式及两个平台的登录方式选择页共用 `BetaLoginArtworkFrame`。插画保留缩小后的高度，横向拉满两侧；表单与插画分区排列，至少留出 24 逻辑像素间距。键盘出现或短横屏时隐藏装饰，让出输入空间，保留字段焦点、输入内容及滚动状态。未改欢迎页、账号管理或平台切换页的插画。

## 维护入口

- `lib/features/music_platform/netease/together/netease_together_exit.dart`：确认和结果反馈；控制器负责请求与同步生命周期，页面不直接操作音频。
- `lib/features/music_platform/netease/messages/netease_message_card.dart`：有界结构解析、时长单位、网页目标校验；`netease_message_card_view.dart` 负责展示和详情导航。
- `lib/features/music_platform/netease/netease_account_source_info.dart`：只读账号音源信息及共享顺序说明；复用已有 retained Kugou 身份。
- `lib/features/auth/presentation/beta_login_artwork_frame.dart`：共用插画布局；生产登录页继续持有自己的登录请求、取消代次和凭据保存流程。
