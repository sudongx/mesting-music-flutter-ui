# 1.0.62/code83 — 汽水本地接入候选

本版将汽水适配器接入现有 Android Mesting 应用，不增加外部服务器。版本名称
为 1.0.62/code83，沿用 com.mesting.music、beta 内部渠道和原签名。这是本地
接入候选，不能据本地协议夹具或主机截图宣称真实手机号认证、完整媒体、奖励
到账或官版音效已验收。

## 已实现的代码路径

- 汽水独立的手机号/短信入口；获取验证码不会发布账号。Passport 返回凭据后
  再读取 `/luna/me` 确认其 Luna 资料，分开保留两种用户 ID。使用现有 retained
  vault 独立键保存私有 Cookie/令牌并回读；公开身份只携带登录代次摘要。
- 三平台切换保留各自凭据；恢复失败保留旧加密内容。切换/退出撤销旧请求与
  私人页面显示，令牌刷新保留本次登录代次。汽水不会进入酷狗或网易云上报器。
- 汽水的发现、音乐、我的三个目的地复用原导航，内部保留 0/1/3 分支映射。
  歌单、搜索、喜欢、历史和听歌模式使用各自移动端契约；空数据与业务拒绝
  可见，原两平台继续使用其原入口。
- 歌曲解析只使用媒体响应返回的地址，CDN 请求匿名；先核对时长和实际音频
  头，拒绝已识别的试听和加密媒体。播放复用唯一播放器、歌词和队列。
  下载另核对精确歌曲/音质的 `need_download_quota == false`，不自行消费配额。
- 权益页区分活动免费 VIP 和广告奖励时长。用户主动领取前重读服务器日期及
  资格，先持久记录再提交；未知结果不自动重放，不用历史日历项确认今天。
- 官版 DSP 的 14 份默认图仅作为原样配置来源。仅展示已由当前账号明确授予、
  未过期并可手动使用的配置，不将通用 VIP 推定成全部音效资格。PCM 桥接到
  唯一现有 Media3 音频链，失败回普通播放，换账号/非汽水歌曲/到期清除配置。

## 仍缺失或未验收

1. BDInstall 成功注册所返回的安装标识及动态原生安全因子没有恢复。本地
   适配器仅读取真实 Android 公开上下文，不伪造 iid/device_id，不接公共
   签名服务。因此服务端可能拒绝短信或媒体请求，当前没有成功真实认证证据。
2. 安全验证只展示服务器返回且在允许域名内的 HTTPS 页面；WebView 与
   Passport 的票据/Cookie 回传协议尚未接通。关闭页面不会被视为验证成功。
3. 用户随后连接手机并授权直接安装。已通过 ADB 将 1.0.61/code82 保留数据
   覆盖为 1.0.62/code83，核对版本和原首次安装时间。未卸载、清数据、启动
   应用或操作音乐账号/短信/奖励/后台。此结果仅证明包替换；真实会话恢复、
   完整播放/下载、键盘、系统返回、GPU 和 DSP 输出均待验。
4. 广告奖励的真实任务凭证、奖励时长及连续领取未实现。活动免费 VIP 不能
   冒充模块的广告奖励时长；真实到账也未证明。
5. 消耗配额的下载、加密媒体解密、云歌单创建/编辑/删除、完整搜索/历史分页
   尚未实现。当前搜索读取服务端首批，历史读取最近 50 项；打开歌单会顺序
   读取全部服务端分页（有取消、重复游标及上限保护），尚未改为界面逐页续载。
6. 当前可识别 MP3/M4A/FLAC 文件头；无法确认格式或音质时拒绝相应操作，
   不把媒体响应宣称的码率当作已实测音质。
7. 原有 QQ/微信原生登录、酷狗官方累计统计入账、旧失效密钥/旧密文、网易云
   历史总时长及十月 683 分 10 秒等历史问题沿用，旧日志没有补发。

## 原生 DSP 的范围

原官版三份 ARM64 ELF 保留原 SHA-256，具有 4 KiB 页对齐。它们以应用内资源
保存，未放入全局 JNI 库目录；仅在用户明确选择、账号资格通过且进程为
ARM64/4 KiB 时提取至本应用私有 code cache，按固定 SHA-256 核对后装载。
ARM32/16 KiB 进程拒绝该音效并保留原播放器。此隔离不等于官版二进制已经
兼容 16 KiB，也不是设备上的成功输出证明。原 12 份非 app 原生库、定制引擎
与 7 份着色器应在实际 APK 中逐项对照 1.0.61。

第三方原始二进制仍属原权利方；PROVENANCE.json/NOTICE.md 随本地源码及
候选包保存，不能据此推断开源或再分发授权。未上传、推送或发布。

## 维护入口

`lib/features/music_platform/qishui/` 分开管理私有会话、固定域名协议、登录、
DTO、仓库、账号生命周期、页面、权益和音效资格。`QishuiOwnedPage` 统一
撤销私人页面；共享 library/profile/quality/download/lyrics 适配器按汽水
显式分发。`QishuiContextPlugin.kt` 仅读公开系统上下文。just_audio 的本地
`AudioEffectBridge.java` 与 `SodaAudioProcessor.java` 只负责固定二进制装载、
PCM 格式转换与音频线程句柄生命周期，不承载登录或权益协议。

所有验证和失败原始记录位于 `.codex-artifacts/2026-11-06-soda-integration/`。
最终数字与产物身份以同目录 host-check-summary.json、实际 APK/source
verification 和 docs/validation-2026-11-06-v1.0.62.json 为准；本文不累加历史
原生、SDK 或真机验证结果。
