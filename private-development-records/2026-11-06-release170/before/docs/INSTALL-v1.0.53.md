# Mesting Music 1.0.53 安装与验收

本地原签名APK：`release/Mesting-Music-v1.0.53.apk`。完整源码：`Mesting-Music-v1.0.53-source.zip`。包名`com.mesting.music`，code74；不上传或发布。旧`.beta`仍是另一个应用，不能直接覆盖，也不自动迁入其私有数据。

安装前不要卸载、清数据或删除旧登录。主机证书/包名核验不能代替手机覆盖升级和账号数据保留验收。

## 受影响设备上的验收顺序

1. 原网络、VPN关闭：冷启动恢复原账号；分别测试酷狗与网易云获取验证码、手动登录及连续播放。验证码送达与登录成功是两个独立结果；等待超时后若收到验证码可手动尝试登录，不连续盲点重复发码。
2. 同一设备、同一网络、VPN开启：重复上述步骤，与官版做同条件对照。记录VPN名称、模式与是否对Mesting分流，由用户自行操作；不将关闭VPN作为修复结论。
3. 已登录状态分别切换Wi-Fi/流量和VPN开关，测试新点歌、暂停/恢复、下一首和重进App。失败时保留当前歌曲、队列、位置及账号，不能自动登录到其他账号或重复计量。
4. 失败后立刻进入“设置→连接与播放诊断”复制本次启动的记录；登录页失败可点“查看连接诊断”，恢复页可点“复制恢复诊断”。记录不含真实登录内容，复制不会探测账号。当前版本中只能获得本版开始采集的内存证据，不能追溯52日志。
5. 欢迎页不操作观察至少30秒：循环挥手、眨眼继续存在，点击仍会打招呼；分别在无录屏/浮窗和有原监测工具的条件下观察GPU及频率，记录工具口径。切到后台或被新页面覆盖时角色应暂停。主机帧需求降低不能直接折算成GPU百分比或功耗降低。
6. 覆盖升级后核对两个音乐平台登录、多酷狗账号、各自队列/进度、本机喜欢/下载/末播与完整玻璃。播放成功后再观察新听歌的接口回执、官方读回和跨日结果，不补发旧记录。

若仍出现恢复页，先复制恢复诊断。本机加密存储错误不等于音乐平台账号失效，不要为试验先清除App数据。当前未获手机/ADB、真实音乐账号或后台访问授权，本轮没有执行这些验收。

实现、代码入口和证据边界见`fixes-2026-11-04-v1.0.53.md`。历史网易云总时长及十月683分10秒仍未解决；独立设备/锁屏等一起听待验收范围保持旧记录。
