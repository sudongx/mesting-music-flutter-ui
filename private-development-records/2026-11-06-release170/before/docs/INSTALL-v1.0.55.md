# Mesting Music 1.0.55安装验收

本地包：`release/Mesting-Music-v1.0.55.apk`。完整源码：`Mesting-Music-v1.0.55-source.zip`。版本1.0.55/code76，包名`com.mesting.music`，原签名。最终大小/哈希见对应SHA256及verification文件。仅本地交付。

1. 在现有54上覆盖安装，保留应用数据和当前新登录。先保持VPN关闭，打开后检查是否恢复当前账号；清后台再打开复核。不要先卸载或清数据。
2. 若旧凭据明确提示“登录密钥已失效”，使用重新登录。55保留原加密字节；不可用的旧密钥不能靠重复读取复原。新认证成功后，再清后台重开验证持久恢复。
3. 在“我的→切换平台”选择另一平台。旧会话可读时直接切换；不可读时在该页点“重新登录网易云/酷狗”。取消登录应仍保留原平台；成功后可双向切换，无需先退出当前账号。
4. 网易云首次进入后检查头像、每日推荐/私人FM/歌单封面和歌手榜。遇到单张失败可点重试，当前页面应能恢复，相邻成功封面继续显示；不以重开软件作为唯一恢复方式。
5. 酷狗检查听歌统计、乐龄、听歌等级、榜单和徽章。需要官方功能授权时，用同一账号扫码确认；返回后应主动刷新，也可单项重试。关注详情页的具体错误和读取时间，保留旧“今日收听”不等于新读取成功。
6. 用户自行在同设备、同网络、同VPN节点开/关及Wi-Fi/流量切换条件下复核两平台、图片和完整歌曲播放，检查暂停/拖动/下一首/缓存/下载、大歌单及各账号队列。循环角色和完整玻璃保持。

如仍失败，在退出进程前复制设置中的“连接与播放诊断”。schema2仅当前进程最多80条固定类别；新的资料阶段可区分请求/响应、解析和授权。不要提供密码、验证码、Cookie/Token或敏感VPN配置。

本轮没有连接手机/ADB或访问真实账号、业务后台；主机TLS和合成协议数据不是生产CDN、设备Keystore或VPN验收。欢迎页GPU、历史总时长及十月683分10秒、既有一起听剩余设备范围保持原边界；旧已接收/未知计量和旧原生日志不重发。旧`.beta`包名不同，不能由本包直接覆盖或自动迁入私有数据。
