## 版本与升级说明

同名版本号不代表同一安装通道，请同时核对包名、Android code 和签名。较高 code 通常不能被较低 code 覆盖安装；历史 APK 用于留档和主动验收，不能当作应用内自动回退。私有诊断候选、签名私钥、密码、手机记录和构建缓存不在此次公开附件中。此次只归档 Git/GitHub，没有操作音乐更新后台。
