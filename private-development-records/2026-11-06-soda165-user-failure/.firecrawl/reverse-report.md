# 汽水音乐逆向报告 \+ 签名后端实现

[Permalink: 汽水音乐逆向报告 + 签名后端实现](https://github.com/zihe114514/qishui-reverse-report#%E6%B1%BD%E6%B0%B4%E9%9F%B3%E4%B9%90%E9%80%86%E5%90%91%E6%8A%A5%E5%91%8A--%E7%AD%BE%E5%90%8D%E5%90%8E%E7%AB%AF%E5%AE%9E%E7%8E%B0)

> 抖音系音乐 App「汽水音乐」(SodaMusic / Luna) 的完整逆向分析报告,以及一个可直接运行
> 的本地签名后端(qs-backend)——覆盖 **登录、搜索、取流、下载解密、歌单、推荐** 全链路。

## 一句话结论

[Permalink: 一句话结论](https://github.com/zihe114514/qishui-reverse-report#%E4%B8%80%E5%8F%A5%E8%AF%9D%E7%BB%93%E8%AE%BA)

汽水的接口防护是 **三层结构**,第三层(`X-Helios`/`X-Medusa` 应用级签名)锁死了
完整版取流,而它只能由官方客户端自带的 `bdms.node` 计算—— **不要逆向它,直接加载它**:

```
免签名    → 目录数据面(搜索/歌单/推荐/歌词)     → 全量元数据
免签名    → /luna/h5/*                          → 30~60s 试听(未加密 m4a)
bdms.node → /luna/pc/*  +  X-Helios/X-Medusa    → 完整版 + CENC 密钥(SVIP 权益内)
```

## 实测效果

[Permalink: 实测效果](https://github.com/zihe114514/qishui-reverse-report#%E5%AE%9E%E6%B5%8B%E6%95%88%E6%9E%9C)

- VIP 曲目完整版取流: **5 档音质、全时长、CENC 解密落盘**(SVIP 账号实测 4/4)
- 解密文件 mvhd 实际时长与全曲分毫不差(202s/202.1s、308s/308.2s)
- 登录:扫码 \+ Cookie 导入均可用;风险二次验证(2046)需官方 App 完成

## 环境要求

[Permalink: 环境要求](https://github.com/zihe114514/qishui-reverse-report#%E7%8E%AF%E5%A2%83%E8%A6%81%E6%B1%82)

- Windows 10/11(签名组件只有 Windows/macOS 版)
- 本机安装 **汽水音乐官方客户端**(签名要加载它自带的 `bdms.node`)
- Node.js 18+(打包版已内置 `node.exe`,免安装)
