## 手机诊断步骤

1. 先确认允许覆盖安装。覆盖安装会暂时中断当前播放；原包名、证书及更高版本码已在主机核验，真实数据保留与安装仍待验证。不要卸载或清除数据。
2. 安装后由用户重新进入一起听房间。保持 Mesting 前台，让好友切歌、暂停、播放；记录大致操作时间。
3. 切到桌面，由好友重复操作并等待至少 20 秒；再回到 Mesting，观察是否补同步。后续锁屏对照仅在用户同意并准备好时进行。
4. 最多采集约 3 分钟应用的脱敏阶段记录。若用户自行安装，可在“一起听 → 同步诊断”读取、预览并复制本机报告。诊断仅读取本机状态，不上传，不请求平台或控制播放。
5. 本候选显式开启 `TOGETHER_SYNC_DIAGNOSTICS`，将白名单阶段写入 `MestingTogetherSync` 标签；普通构建默认关闭。取得证据后再修复实际停止环节，不能把候选安装成功或主机模拟成功当作后台同步已修复。
