# 1.0.53 连接、登录、缓存音频与欢迎页渲染

版本：1.0.53/code74，`com.mesting.music`。本轮按用户确认同时处理 Wi-Fi/流量及 VPN 开启/关闭下的播放与登录稳定性，保留循环角色动画、完整玻璃、原签名和现有功能。用户提供的设备为小米14/澎湃OS4及OPPO平板；官版同网络可用。**没有连接这些设备，也没有实际操作 VPN、真实音乐账号或业务后台。**

## 已确认的代码问题与处理

1. 欢迎角色原来用六秒 `repeat()` 在所有静止间隔持续驱动帧。改为同一节奏的挥手、眨眼加静止间隔定时器；动时直接通知 painter，不重建整个登录/玻璃树。保留点击打招呼、主题、减少动态效果及离屏/后台暂停。主机120Hz六秒采样的帧需求由原持续ticker约720帧变为193帧；这不是手机GPU、功耗或100%占用已经消除的证明。
2. 初次 `setAudioSources` 错误被加载期的播放器事件保护排除，因而旧的异步直连恢复未必触发。现在初次缓存网络错误可恢复同歌曲、同音质一次；程序/解码错误不混入网络恢复。新点歌、暂停、切号等仍受原 epoch 保护。
3. 旧直连路径传入空 headers，播放器仍可能再次创建本机HTTP代理。现在空 headers 传 null，正式播放器通过原生方式交付公开音频请求头。缓存正常可用时继续缓存；需要恢复时才走真正的原生音源路径。
4. 缓存请求缺少明确的连接/响应/数据空闲等待上限，失败的共享 fetch future 还可能产生第二条未处理异常。补充12秒空闲上限、socket取消、失败清理与共享错误消费；完成缓存先 flush/close，完整长度核对后原子改名。等待上限不限制整首歌或总下载时长。
5. 保留酷狗实际返回的同录音/同音质 URL 列表中的最多两条备用地址。主地址缓存及直连都失败后才依次尝试；不推算域名、不修改签名、不更换平台或降级音质。解析新的主音源时默认清除旧备用地址。
6. 音乐请求现在对头部与正文设置同一个截止时间并触发 AbortableRequest。只对明确白名单读取最多尝试两次；验证码、登录、点赞、计量等写入不自动重放。酷狗适配器的HTTP502也可能是业务错误，设备注册/权限/安全验证代码保留原合同，不把它们一概当网关错误。
7. Android 支持的音乐 HTTPS 请求增加系统 `HttpURLConnection` 桥接，使用系统DNS、TLS、代理及默认网络路由，不绑定物理Wi-Fi/流量、不主动绕过VPN、不忽略证书。连接按短事务关闭，减少网络切换后的旧连接复用。凭据只通过请求私有字段传入，不进日志或全局cookie jar。取消会断开对应连接，超时写入不切换另一个传输重发。
8. 网易云验证码发送必须取得明确200业务回执。异常提示区分连接和平台回复；网络分类不塞进原 `MusicPlatformException.code` 业务码，防止计量模块把未知网络结果误记成明确拒绝。后台超时诊断保留 TimeoutException 语义。
9. 账号恢复首先读本机加密存储，不能仅凭 VPN 开启就认定为网络故障。安全读取补充有界重试，使挂起的读取不永久占住酷狗账号串行队列；失败不删除、不重置密钥、不改明文存储。持久写入、回读确认及账号归属仍由原仓库负责。

## 网络与本机恢复证据

设置新增“连接与播放诊断”，登录失败可进入，恢复失败页可复制恢复诊断。仅在当前进程内保留最近80条固定分类、数字状态、耗时和尝试次数；不包含手机号、验证码、账号ID、cookies/token、完整URL或原始异常。查看/复制不触发发码、登录、补发或账号探测，退出进程后不保留本次内存记录。

系统HTTPS桥目前由音乐客户端使用；网易云官方HTTPS走该桥。酷狗既有Rust协议与本机回环服务保留，未冒充已经迁移到Java桥；这也是实际VPN验收仍必须分别覆盖两平台的原因。宿主/测试环境或未提供桥的引擎只在 MissingPlugin（未派发请求）时保留Dart传输，不在不明写入结果后重发。桥在冷启动首次尚未注册时，仅该次请求可回落；下一次请求重新检查桥是否就绪，不永久缓存未就绪状态。完整大歌单详情保留原Dart传输，避免平台消息的正文缓冲上限截断既有曲库。

## 验证与限制

最终整文件计数、首轮失败与成功复跑替换、截图及原生验证见本版 validation JSON；不重复累加复跑。APK核验另列原证书、包名/code、双ARM、原定制引擎、7份shader、8份旧库和2份SDK缓冲库。SDK源码及锁未升级；SDK既有563项只保留原范围的历史结果，不计成本轮重跑。
