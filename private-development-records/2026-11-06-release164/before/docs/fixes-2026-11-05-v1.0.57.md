## 榜单布局与操作

`platform_ranking.dart` 负责真实元数据、公开分享链接及完整分页；`platform_ranking_header.dart` 负责页面状态与交互。页面在任何账号／令牌切换后撤销原操作周期，即使快速 A→B→A 也不会发布第一轮迟到结果。

按最后参考图使用大面积主题色与淡封面背景、居中平台名称和榜单大标题、真实更新日期／期号；收藏、评论、分享放在一条带分隔线的玻璃胶囊中，播放全部位于歌曲列表上方。大字体保持原文字缩放并允许胶囊横向滚动；垂直滚动后显示返回与紧凑标题。共用按钮新增嵌入胶囊模式，保留整条玻璃材质、分区点击、焦点、反馈及拖动取消。

- 播放全部和整榜下载在操作时读取所有页，保持平台顺序并去重；重复页、账号变化或总数缺尾时明确失败，不用第一页替换原队列。
- 酷狗分页游标依据原始条数推进；个别无效录音不能让 30 条原始记录被错误认作不足一页。
- 网易云使用真实歌单订阅与权威状态读回，评论进入现有歌单评论页；失败回执不自动再次收藏／取消。
- 酷狗按用户明确接受的方式，把收藏当天该期完整榜单保存为普通酷狗云歌单，名称包含日期／期号，不随明日榜单更新。先读回已有同名歌单，再按缺少的录音分批保存，最后完整读回；不自动重发结果未知的批次。
- 酷狗胶囊明确显示“收藏本期”和“歌单评论”；评论属于生成的云歌单。未取得官方榜单评论资源，不把此功能描述为官版榜单公共评论区。
- 分享调用系统分享面板，内容仅包含榜单名和官方公开链接；不夹带凭据，也没有代用户向联系人发送消息。

## 酷狗听歌统计

查明并修复的本地问题：

1. 资料读取成功后原先会永久复用快照；现在成功结果有两分钟有效期，已打开的当前日／周／月和等级可重新读取。手动刷新仍可强制读取；失败保留上次成功值，错误项由用户重试。
2. 同步侧独立取得的官方日统计此前没有更新页面共用读取器；现在仅在同账号授权周期内同步该官方快照，并刷新已查询的当前周期。迟到旧请求不能覆盖更新的官方观察。
3. Lite 等级明确业务拒绝此前被归入结果未知，可能挡住后续正常新片段；现在仅新得到且已解析的明确拒绝记为拒绝，显示独立数量，允许后续新听歌按原规则继续。历史未知／已派发记录不会重新解释或补发。
4. 标准等级读取／上报的原响应体逐块超时可能被持续小包无限延长；改为覆盖请求头与完整响应体的总截止和 1 MiB 上限，超时会取消且不自动重发。

**本轮不能证明官方日／周／月或累计时长已经入账。** 本地“听歌回顾”、历史接收回执、等级读回及官方统计是不同事实；本地计量不能直接加到官方数字。静态分析与匿名读取没有确认当前统计写入的完整服务条件，尚需真实账号正常新听歌、相同账号官版对照和跨日核对，不能宣称本地缓存修正已解决全部后端入账问题。

## QQ / 微信原生登录：尚未接通

已区分“另一设备扫码”和“调用本机 QQ／微信授权”。酷狗官版 QQ 路径使用 SDK 发起授权，再由平台交换会话；微信使用 `SendAuth.Req`。Mesting 目前没有获批的原生接入身份，也没有平台批准的 QQ／微信凭据交换路径。

- [微信 Android 常见问题](https://developers.weixin.qq.com/doc/oplatform/Mobile_App/FAQ/Android.html)：接入核对移动应用 AppID、包名和签名；`sendReq` 返回成功不等于授权成功。
- [QQ 开发联调问题](https://wiki.connect.qq.com/%E5%BC%80%E5%8F%91%E8%81%94%E8%B0%83%E7%9B%B8%E5%85%B3%E9%97%AE%E9%A2%98/)：包名／签名不匹配可产生 100044。
- [QQ 登录接入](https://wiki.connect.qq.com/qq%E7%99%BB%E5%BD%95/)：SDK 回调的应用范围 openid / access_token 不能直接代替音乐平台会话。

因此本版本不展示没有可用授权链路的“已接通”入口，不借用官版应用身份。现有登录方式保留；这项需求仍未完成，需获批身份及音乐平台支持的会话交换后再接入。
