# Mesting Music 1.0.54 安装与验收

本地原签名安装包：`release/Mesting-Music-v1.0.54.apk`。完整源码：`Mesting-Music-v1.0.54-source.zip`。正式名称 Mesting Music，包名 `com.mesting.music`，版本 1.0.54/code75。没有上传或发布。

## 安装

在现有 1.0.52/1.0.53 上选择覆盖安装，先保留应用数据和旧登录。包名、原证书和递增版本码已由主机核验；手机上的实际覆盖升级与数据保留仍需验收。旧 `.beta` 是不同包名，不能按同一应用覆盖，也不会自动迁入其私有数据。

恢复旧账号失败时，先复制恢复诊断，再点“重新登录”，用当前本人账号完成平台认证。54 提供独立加密恢复通道，避免旧存储读取失败持续阻断已认证的新登录；没有删除、重置或覆盖原来不可读的账号库。登录成功需要凭据完整、加密保存与回读均完成，短信送达或 HTTP200 均不单独代表成功。只有旧库实际失败时才启用恢复通道，正常可读的多账号库继续原流程。

## 同一故障设备上的顺序

1. 保持原数据、关闭 VPN，覆盖安装后测试冷启动恢复。若失败，复制诊断，再通过“重新登录”恢复。登录成功后彻底结束 App 再打开，确认能恢复同一账号，而非仅当前进程可用。
2. 开启原来同一个 VPN、同一节点，重复冷启动、验证码、登录和完整播放；再关闭 VPN 重复。由用户自行操作 VPN 与设备，测试目标是两种状态均可用，不要求通过关闭 VPN 使用。
3. 网易云、酷狗分别播放数首明确的歌曲到结尾，检查暂停/恢复、下一首、拖动进度、下载和完整歌单；在 Wi-Fi/流量及 VPN 开关之间切换后再点新歌曲。失败时保留当前账号、曲名、队列与位置。
4. 检查多酷狗账号切换及各自队列/进度、喜欢、末播、下载和其他现有功能。旧库不可读而使用恢复通道时，只展示新认证可用的账号；旧账号加密数据仍保留，不伪造其他账号已恢复。
5. 欢迎页保持不操作至少 30 秒：角色应继续循环挥手、眨眼，完整玻璃保留；离屏/后台暂停。分别用原监测工具及关闭录屏/浮窗的条件观察 GPU 与频率，记录测量口径。本轮没有手机 GPU 测量。

## 如果仍然失败

在失败后、退出进程前，打开“查看连接诊断”或“设置→连接与播放诊断”复制本次记录。恢复页也可复制恢复诊断。schema2 仅在内存保留最近 80 条白名单分类，可分辨本机读取、解码、写入、回读、独立恢复、平台凭据校验和账号发布；不包含手机号、验证码、cookie/token、账号 ID、完整 URL 或原始异常。

不要为采集先清数据，也不要反复盲点发码。诊断查看与复制不会重新登录、发码或补发旧计量。底层密钥失效、系统存储无法写入或平台认证拒绝仍可能导致实际失败；54 会保留可保留的数据并给出所属阶段，不能在无设备证据时宣称这些情况已全部解决。

实现及本轮验证见 `fixes-2026-11-05-v1.0.54.md`、`validation-2026-11-05-v1.0.54.json`。未使用手机/ADB、真实音乐账号、业务后台或修改 VPN 配置。网易云历史总时长及十月 683分10秒仍未解决，旧已接收/未知记录不重发。
