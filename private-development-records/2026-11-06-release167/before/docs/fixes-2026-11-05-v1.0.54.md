# 1.0.54 账号持久恢复与系统网络一致性

版本 1.0.54/code75，`com.mesting.music`。按用户确认实施，保留原签名、循环角色、完整玻璃、定制引擎和既有功能。本轮仅本地代码、主机测试、构建与交付，没有手机/ADB、真实账号、后台、VPN 设置、提交推送或发布。

## 故障证据与结论边界

用户在 52→53 覆盖升级后立即进入恢复页；验证码可收到，HTTP200 登录之后仍报本机资料读写失败。清数据并关闭 VPN 可暂时登录，但关闭 VPN 冷启动也恢复失败。四条旧 `other/restore/storage/0ms` 记录没有原生错误族，不能据此认定 VPN、密钥损坏或某一种设备故障是唯一根因。

已从当前及冻结源码确认：旧挂起原生读取可能因 Future 截止重复堆积；新登录依赖旧库读取；远端凭据格式错误被混报为本机存储；Android 插件 `apply()` 的完成不等于同步持久化；53 的系统桥未覆盖酷狗 Rust 真正的外网出口。54 修正这些明确问题，并增加分阶段证据。**首次设备故障的底层原因、受影响设备 VPN 开关下实际恢复及播放效果仍待安装验收。**

## 存储与账号边界

- `retained_secure_read.dart` 对同一存储/键复用尚未结束的原生读取。8秒是等待方截止，不伪造原生取消，不在挂起时重发；只有已经结束的可重试平台错误才有限重试。
- `credential_failure.dart` 将读取、解码、写入、回读等异常包成专用类型，只从固定原生错误族取分类，不解析异常正文。平台返回凭据不全单独记录 `credentialValidate`，HTTP200、认证、保存和账号发布分别确认。
- `RetainedCredentialVault` 保留原 key/算法/序列化。原库失败后的显式、平台验证完整的新登录，可写到独立 Android 加密命名空间 `mesting_verified_recovery_v1`，同步提交后回读，之后冷启动优先恢复；原不可读字节和其他账号不删除。恢复槽有回滚及退出 tombstone，避免退出后旧账号复活。正常可读的多账号继续原快照及账号隔离。
- 本地 `flutter_secure_storage` 10.3.1 fork 仅修补 Android 持久化和调用边界：数据、包装密钥及算法标记使用 `commit()` 并检查结果；按实际命名空间独立串行队列，避免旧库卡住新恢复库；提供固定错误族。保留 `resetOnError:false`、原密码算法、原别名及格式，不改全局 Pub 缓存。上游 Dart 测试未作为应用测试运行；本轮 Android Java 经实际 Gradle 编译，固定错误族另有六项 JVM 用例。
- 依赖锁唯一语义变化是该包 10.3.1 的 hosted→项目内 path，其余条目及 SDK 约束逐条核对。原锁另存私有证据，不能称整份锁字节未变。

## 网络与完整流

- `SystemMusicIoClient` 负责应用拥有的流式 HTTP：每次请求读取 Android 当前系统代理/网络代次，使用系统 DNS，IPv6/IPv4 间隔竞速，取消和关闭输掉的连接。回环服务始终直连本机；不固定 IP、不绑定物理 Wi-Fi/蜂窝、不修改 VPN/DNS/代理设置、不忽略证书。
- 音乐小 JSON 请求仍走方法通道，原生公共交换层改为固定 OkHttp 5.3.2（Okio 3.16.4）。使用系统 DNS/代理/TLS、快速地址回退、独立 cookie 所有权、取消与完整事务截止。手动处理允许的重定向，跨主机去除私有头；POST 307/308 不重放。禁用不确定请求的连接重试，并阻止库对 408/421/503 的隐式重发。421/网络变化退役旧连接，不删除账号。
- 酷狗 `request.rs` 保留签名、加密、序列化、cookie/SSA 与模块合同，将 Android 真正的外网交换接到同一原生层。Java 发起 JNI 安装，捕获 JVM/类引用后供 Rust 线程使用，避免冷启动工作线程查类问题；就绪确认发生在外网派发前。桌面原传输保留，不在未知写入结果后换传输重发。
- Rust 音视频代理通过独立流式 JNI 管道分块读取（每块至多64KiB），与小体积 JSON 方法消息上限分开。EOF 可重复读取且不会重复查已关闭句柄；关闭/失败释放流。大列表、上传、更新下载、图片和音频缓存继续流式传输，不套用小消息正文上限。
- 共享缓存请求安装系统客户端工厂，保持 Range、完整性和53的首次失败恢复、原生直连及同录音真实备用地址；不换歌、不擅自降低音质、不重放计量。原生播放器继续使用既有 Android 网络栈。

新引入的 OkHttp/Okio Apache2.0 说明与 FSS BSD 许可均随源码及 APK 资产保留。Android 增加普通 `ACCESS_NETWORK_STATE` 声明以观察默认网络，无新增运行时权限提示。
