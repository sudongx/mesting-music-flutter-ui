通过系统安装器保留数据覆盖同签名同包名版本；不要清除数据、卸载或删除原账号。本轮没有操作手机，80→81升级与冷恢复仍需实际验证，不能继承56同code77覆盖的历史结论。

1. 打开并核对双平台登录、队列、签到日历和自动签到开关是否保留。
2. 到网易云签到页刷新免费听余额与进度，确认与官版一致。
3. 点击一次“广告领取”。第一次平台确认后立即点击“停止领取”，本轮先只验证一次；当前连续流程在两次申请之间保留等待，可随时停止后续请求。
4. 在官版独立核对实际剩余时长和领取进度。仅有本机提示或code200不足以证明到账；请保留本次确认次数和实际时长变化。
5. 若失败，记录完整提示中的阶段及“业务码/HTTP”标识。在设置的“连接与播放诊断”复制本次记录，保留失败后本次启动的记录即可，不需提供Cookie、入口URL、账号凭据或广告资料。
6. 若提示“入口未识别”“未提供直接领取资格流程”或“入口未提供有效来源”，表示本机未提交奖励领取，请报告原文。不能通过猜source或任意打开返回URL继续。
7. 若提示“结果尚未确认，不会重复提交”，本次写可能已到达平台。独立核对后反馈，不反复点击试领；余额增加本身也不能自动归因到这笔未知写。
8. 单次实际到账确认后，再验证连续领取、停止和平台限制。失败或需验证会终止，不承诺无需真实广告凭证即可到账。

本轮仅本地主机验证，未访问真实音乐账号、手机/ADB、VPN或业务后台。实际领取、80→81保留数据覆盖、冷恢复、网络图片播放及GPU仍待验收。
