# 1.0.67：汽水官方音源、歌单管理与页面重排

用户确认：汽水只使用官方音源；按官版内容结构重排，但保留 Mesting 完整玻璃和底部导航。
仅汽水“音乐”根页面隐藏胶囊播放器，并将听歌模式移到标题旁下拉框。网易云和酷狗布局、
自动补源和下载选源规则保持。手机号路线继续停止，不恢复短信或原生注册调查。

## 媒体请求与提示

- 原扫码会话将媒体接口映射为普通 GET，异常又统一兜底成“检查网络”。本轮手机复现日志
  确认错误发生在媒体请求阶段。公开匿名对照中，普通 GET 即使带44字符 Web SDK签名，
  仍为 HTTP 200 空响应；它不能替代桌面应用逐请求签名。
- 依据固定版本的 myMusic / libresoda 对齐 POST `/luna/pc/track_v2`、准确 JSON body、
  uppercase MD5 `X-SS-STUB` 和 `x-helios` / `x-medusa`。JSON只编码一次，签名后不改body。
- 用户明确选择参考项目所用外部签名服务。服务只接收官方目标URL、请求方法、body和
  限定的应用头；Cookie、CSRF、账号token和扫码nonce不发送给服务。返回头只接收两个
  签名头，不能覆盖认证或重定向请求到其他host。音频和歌单请求直接发往汽水官方。
  参考实例目前使用HTTP，Android只增加其准确主机的明文例外，不放开全局策略。
- `/config`在当前参考实例返回404；使用无账号凭据的签名请求读取其公开device_id，
  再对齐PC协议上下文。该上下文不是Android BDInstall或Mesting手机安装身份。
- 已实测无账号Cookie也能得到签名和有效官方`track_player`，但该匿名例曲只有60秒，
  因此不能据此宣称真实账号或完整歌曲通过。试听与权益不足明确提示，不使用其他平台源。
- 官方media DTO补齐`track_player`、嵌套JSON、PascalCase播放资料及CENC授权字段。
  只有服务端返回的本次授权才能解码；临时播放缓存不等同于用户下载权利。
- 汽水提示统一调用已有顶部状态HUD，分别呈现连接、超时、签名拒绝、资料格式、权益
  和未知写入结果。播放器按钮捕获异步错误，避免未处理异常及底部旧SnackBar。

## 歌单与下载

- 新增独立歌单详情、编号歌曲、播放全部、随机播放、歌单搜索、显示排序和root抽屉。
  批量页支持多选、全选、拖动排序、添加到歌单、下载和删除确认；添加歌曲从汽水搜索
  选择，隐私由本人明确提交。自己的歌单由当前官方owner或官方“我喜欢”类型核对。
- 创建、信息更新、增删歌曲使用已核对的PC JSON契约。排序使用特殊的
  `/luna/me/playlist/media/sort`，不盲目添加`/pc`。写入后重新读取真实歌单确认。
- 操作日志只保存账号/操作摘要。未知回执跨页面/重启保留，重新点击先只读核对，
  不自动重发；确定拒绝与提交后未知结果分开处理。主机fixture不算真实账号增删验收。
- “导入”支持读取汽水歌单ID或明确的官方链接，展示目标与歌曲数后复制到本人歌单。
  不将其他平台ID当汽水ID，不自动猜同名录音，也未宣称跨平台歌单转换已实现。
- 下载使用官版19.0.0的`/luna/commerce/v2/check_download`及返回音质编号，先核对当前
  账号本音质资格；缺回执、需要额外扣下载额度或未返回完整音频时停止，不静默扣额。
  官方CENC本机解码后的私有缓存通过既有完整性/保存流程发布，不把加密字节当可播文件。
- 正式下载核对当前账号、完成记录、录音ID及保存URI后直接离线播放；临时播放缓存
  仍重新验证官方账号与媒体授权，不将临时文件或其他账号记录当作完成下载。

## 布局与维护边界

- “我的”改为账号歌单封面氛围区、资料头、会员/音效入口、歌单/下载/历史页签及纵向
  歌单列表。官方未返回的社交统计和听歌总时长显示未知，不套用截图数值或伪造0。
  视频、AI写歌及无已验证数据的功能没有冒充接通。
- 歌单收藏/评论计数仅展示实际返回值；文字分享不虚构官方分享URL。评论业务并非本版
  新增的已验收功能。底部抽屉、批量页使用root Navigator避开底部壳遮挡。
- “我喜欢的”位于“我的”的歌单区；从“我的”进入详情仍选中“我的”，返回仍回到原页。
  修正独立详情壳固定选中“音乐”的问题，其他平台默认导航行为保持。
- 协议、请求签名、媒体解码、写入日志、多选排序状态与UI分别独立，注释说明生命周期、
  账号撤销、未知结果与授权边界。外部签名服务成为本版新增运行依赖；自用NAS助手另在
  独立会话研究，尚未安装或部署到NAS。
